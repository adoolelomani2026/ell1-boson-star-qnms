# Relativistic ell=1 boson-star axial modes

Numerical data, Python solvers, symbolic checks, figures, and manuscript sources
for the coupled odd-parity Einstein--Klein--Gordon channel of a relativistic
`ell=1` boson star.

The central result is a long-lived `J=L=2` pole,

```text
sigma = 0.0493977307850 - 5.9651933e-7 i
Q     = 4.1405e4
```

The pole is continued through seven separately solved stable backgrounds.
Every declared local Evans contour has winding number one, and adjacent
normalized six-state profiles overlap above `0.9991`.

## Project status

The repository contains the complete neutral free-field calculation reported in
the manuscript: equilibrium backgrounds, relativistic radial certification,
the closed axial system, complex-frequency searches, local pole counts,
far-boundary studies, time-domain checks, scattering, driven response, and
stationary response.

The remaining scientific limits are stated rather than hidden:

- the Richardson-extrapolated unused axial Einstein monitor has a documented
  finite-difference plateau at `1.5e-7`--`2.2e-7` in relative pointwise norm;
- the ordinary `ell=0` matter-filled stellar QNM has not yet been reproduced with
  the same nonradial pipeline;
- the inferred scattering reciprocity weight is not a canonically derived energy
  flux;
- the short evolution checks the real frequency but cannot measure the
  million-unit damping time independently.

Charged equilibria and the coherent-state occupation model are supporting
studies. They are not corrections applied to the neutral axial eigenvalue.

## Repository structure

```text
.
|-- python/
|   |-- background/       equilibrium and charged-background solvers
|   |-- radial/           BVP and Chebyshev radial pulsation solvers
|   |-- nonradial/        axial EKG, Evans, scattering, and time evolution
|   `-- experiments/      reproducible production and validation runs
|-- symbolic/             generated symbolic operator identities
|-- reports/              machine-readable spectra, profiles, and diagnostics
|-- figures/
|   `-- manuscript/       publication figures regenerated by the build
|-- paper/                REVTeX source, build, and packaging scripts
|-- pdfs/                 current compiled manuscript
|-- tests/                unit, regression, benchmark, and data-contract tests
|-- environment/          direct and pinned Python requirements
|-- .github/workflows/    cross-platform continuous integration
|-- CONVENTIONS.md        frozen signs, units, time dependence, and variables
|-- PROJECT_STATUS.md     certification gates and known limitations
`-- pyproject.toml        install, package discovery, and pytest configuration
```

This follows the artifact-oriented pattern of the accompanying
Schwarzschild--AdS QNM repository: solver code is separated from symbolic work,
numerical reports, PDFs, and reproducibility documentation. Python packaging and
tests are retained because this project uses a larger multi-module codebase.

## Code map

Directory | Purpose
--- | ---
`python/background/` | Relativistic `ell`-boson-star equilibrium equations, continuation, radius audits, and charged extensions
`python/radial/` | Nonlinear global BVP, independent Chebyshev pencil, mode tracking, diagnostics, and uncertainty studies
`python/nonradial/` | Angular projections, six-state axial dynamics, Evans determinants, Schwarzschild control, scattering, static response, and time evolution
`python/experiments/` | Executable runs that regenerate the records under `reports/`
`symbolic/` | Human-readable SymPy reductions for the axial metric and Klein--Gordon operators
`tests/` | Automated checks spanning local algebra, global solvers, stored reports, and physics controls

## Numerical reports

`reports/` contains the exact inputs and outputs used by the manuscript. JSON
records retain conventions, parameters, acceptance gates, residual definitions,
and provenance. CSV files contain sequences and resolution studies. NPZ archives
contain the equilibrium and mode profiles required to reproduce the nonradial
experiments.

The report filenames identify their physical role, for example:

```text
axial/axial_qnm_discovery.json
axial/axial_qnm_checkpoint.json
axial/axial_qnm_branch.json
axial/axial_time_domain_convergence.json
controls/schwarzschild_qnm_benchmark.json
radial/radial_benchmarks.csv
axial/background_ell1_a080_axial_branch.npz
```

See [reports/README.md](reports/README.md) for the complete artifact map and
regeneration commands.

## Requirements

- Python 3.11 or newer;
- NumPy, SciPy, Matplotlib, SymPy, pytest, pypdf, and ReportLab;
- a LaTeX installation with REVTeX 4.2 and the packages used by `paper/`.

Create an environment and install the repository in editable mode:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r environment/requirements-pins.txt
python -m pip install -e .
```

## Running the calculations

Run the complete regression suite:

```powershell
python -m pytest -q
```

Regenerate the principal axial records in dependency order:

```powershell
python -m experiments.schwarzschild_qnm_benchmark
python -m experiments.axial_qnm_discovery
python -m experiments.axial_qnm_checkpoint
python -m experiments.axial_qnm_far_boundary
python -m experiments.axial_qnm_branch
python -m experiments.axial_constraint_checkpoint
python -m experiments.axial_numerical_robustness
python -m experiments.axial_time_domain_checkpoint
python -m experiments.axial_resonant_response
```

Rebuild the paper, repository figures, and repository PDF:

```powershell
python paper/build_preprint.py
```

The build writes temporary compilation products under `tmp/`, packaging inputs
under `output/`, versioned figures under `figures/manuscript/`, and the current
manuscript under `pdfs/axial_matter_channel_ell1_preprint.pdf`.

## Validation controls

- two independent relativistic radial discretizations;
- a Schwarzschild Regge--Wheeler/Leaver QNM benchmark;
- base, strict `pi/4`, and expanded local exterior-algebra Evans contours;
- two matching domains and a three-point far-boundary campaign;
- center-start and ODE-tolerance sensitivity scans;
- local numerical-holomorphy checks of the raw and exterior-algebra determinants;
- a seven-background branch with normalized profile overlaps;
- a predeclared driven scan fitted without loading the stored pole;
- regenerated time-domain resolution and Courant-factor comparisons;
- continuous integration on Windows and Linux.
